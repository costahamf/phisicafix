# PhisicaFix — AI-тьютор по физике (PHP + PostgreSQL + OpenRouter)

Сервис для изучения физики с авторизацией, страницами разделов и чатом AI-тьютора.

## Запуск проекта

1. Настройте PHP 8+ и PostgreSQL.
2. Проверьте настройки подключения к БД в `includes/db.php` (логику файла не меняйте).
3. Запустите проект локально, например:
   ```bash
   php -S 0.0.0.0:8000
   ```
4. Откройте `http://localhost:8000/register.php`, создайте пользователя и войдите.
5. После входа перейдите на `index.php`.

## Изображения разделов

Для каждого раздела нужна папка в `images/sections/`:

- `mechanics`
- `electricity`
- `magnetism`
- `optics`
- `molecular_physics`
- `quantum_physics`

В каждой папке должны быть 4 изображения размером **400x300px** в формате **WebP** или **PNG**:

- `concept.webp` (или `concept.png`)
- `laws.webp` (или `laws.png`)
- `examples.webp` (или `examples.png`)
- `tasks.webp` (или `tasks.png`)

Если файл отсутствует, на `section.php` автоматически показывается заглушка с иконкой FontAwesome.

## Загрузка изображений в чате

- Поддерживаются `PNG`, `WEBP`, `JPG/JPEG`.
- Доступны 3 способа: кнопка-скрепка, drag & drop в область чата и вставка через `Ctrl+V`.
- Временные файлы сохраняются в `uploads/` и удаляются после ответа модели.
- Папка `uploads/` уже исключена из Git через `uploads/.gitignore`.

## Основные файлы

- `index.php` — лендинг и карточки разделов.
- `section.php` — страница конкретного раздела с подтемами и изображениями.
- `chat.php` — чат в стиле мессенджера с поддержкой мультимодальности.
- `api/chat.php` — backend чата, запросы в OpenRouter, обработка загрузок.
- `includes/topics.php` — метаданные разделов и карточки.
- `css/style.css` — единый современный dark UI.
- `js/chat.js` — клиентская логика чата и загрузки изображений.
